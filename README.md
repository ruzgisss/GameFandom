# GameFandom

Modern bir oyun içerik ve topluluk web sitesi. Fandom.com benzeri bir platform olarak tasarlanmıştır.

## Özellikler

- Modern ve duyarlı tasarım
- Oyun içerikleri ve rehberleri
- Arama fonksiyonu
- Trend konular
- Reklam entegrasyonu
- Mobil uyumlu tasarım

## Kurulum

1. Projeyi klonlayın:
```bash
git clone [repository-url]
cd gamefandom
```

2. Gerekli paketleri yükleyin:
```bash
npm install
```

3. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

4. Tarayıcınızda http://localhost:3000 adresini açın

## Reklam Entegrasyonu

Reklam geliri elde etmek için:

1. Google AdSense hesabı oluşturun
2. AdSense kodunu `script.js` dosyasındaki `loadAd()` fonksiyonuna ekleyin
3. Reklam yerleşimlerini optimize edin

## Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- Express.js

## Geliştirme

1. Yeni özellikler eklemek için:
   - İlgili HTML bileşenlerini `index.html`'e ekleyin
   - CSS stillerini `style.css`'e ekleyin
   - JavaScript fonksiyonlarını `script.js`'e ekleyin

2. API endpoint'leri eklemek için:
   - `server.js` dosyasına yeni route'lar ekleyin
